The ADI OtoSense™ Smart Motor Sensor (SMS) performs predictive maintenance on low-voltage 3-phase induction motors.

The ADI OtoSense™ Smart Motor Sensor (SMS) performs predictive maintenance on low-voltage 3-phase induction motors. It is a complete, easy-to-setup hardware and software solution that uses advanced sensors and AI-based data analysis to:

  • provide round-the-clock condition-based monitoring of motor’s health. For example, power system, motor shaft balance, and overall performance issues.
  • provide fault notifications.
  • deliver electrical, mechanical, and thermal health diagnostics with severity levels
  • recommend solutions for identified motor and performance issues.

This section describes how the OtoSense ™ system works.

The hardware and software system consists of the following components:

  • The SMS
  • Expert health monitoring software hosted on the ADI OtoSense™ Server
  • Mobile and web applications that allow customers to monitor the status of motors fitted with an SMS

After an SMS is configured and installed on a motor, it begins sending data to the ADI OtoSense™ server, which then begins a learning process where a unique, customized model is created for that particular motor. It measures the multi-axis vibration, magnetic field, ambient temperature, and temperature condition of the motor. With the help of this data, motor health degradation can be detected that could lead to motor faults in the power system, stator winding, rotor, motor shaft/balance, eccentricity, bearing, alignment, cooling system, attachment (i.e. loose foot), and overall motor performance.

After the SMS is configured and installed on a motor, it begins sending data from its on-board sensors to the ADI OtoSense™ Server and initiates a learning process. During this learning process, the analytics create a unique, customized model of the motor whose data is received. At regular intervals, the SMS sends a 2.4 second sample of all sensor data to the ADI OtoSense™ Server.

After the learning mode, the ADI OtoSense™ Server uses the baseline model to detect motor performance anomalies and generate alerts about impending motor issues.

This section describes the OtoSense™ learning mode.

  • This section describes the OtoSense™ learning mode.

  • The ADI OtoSense™ SMS requires a learning period to capture the healthy operation of the motor.

  • The 2.4 second sample sent by the SMS to the Server includes:

  • Vibration X-Axis (raw data)
  • Vibration Z-Axis (raw data)
  • Magnetic Field (raw data)
  • Environmental temperature
  • Motor temperature
The proprietary algorithm extracts the most useful parameters from the data samples to generate a baseline model tailored to each motor’s operation. This model will be used to monitor changes to the motor's health.

  • This learning mode has three stages:

  • Quick Learning (approximately seven days)
  • Predictive Learning (approximately four weeks)
  • Fully Predictive (ongoing)
Note: Note: During the entire learning mode, the motor should run at all RPMs, all temperatures and with all loads that will be seen by the motor in its normal envelope operation in order to create the best model.

The motor object consists of a components map. Each component has a Fault Score Index (FSI) and a Code. The FSI is a value between 0 and 10, which indicates the following motor conditions or state:

  • FSI < ‘5ʼ: Alarm
  • FSI= ‘5ʼ or ‘6ʼ: Warning
  • FSI > ‘6ʼ: Good.
Note: Note: The lower the FSI value the greater the severity of the component fault.

For each component in a Warning or an Alarm state, an appropriate Code is assigned by the ADI OtoSense™ Cloud analytics. Each code defines both the recommended Action and the Description of the associated fault.

Each component has multiple possible codes depending on the severity of the fault.

For example, a Power System component with an FSI of ‘3ʼ or ‘4ʼ will be assigned code ‘1002ʼ and a Power System component with an FSI of ‘2ʼ or below will be assigned code ‘1003ʼ. For more information, see Table 10.
